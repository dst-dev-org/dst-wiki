# 月岩（moonrocknugget）

## 快速判断

- 职责与适用：`prefabs/moonrocknugget.lua` 单注册 1 件 item，官方简中"月岩"（[chinese_s.po L345670-L345672](../../../raw/current/scripts/languages/chinese_s.po#L345670-L345672)）。它同时是建筑修复材料与十余条配方原料；`bank` 与 `build` 不同名（`moonrocknugget`／`moonrock_nugget`），资源只声明 1 个 `anim/moonrock_nugget.zip`（[L1-L4](../../../raw/current/scripts/prefabs/moonrocknugget.lua#L1-L4)、[L17-L19](../../../raw/current/scripts/prefabs/moonrocknugget.lua#L17-L19)）。
- 优先使用：要判断"它能修什么／修多少"看下文"修复供料口径"；要接雪人装饰看 `snowmandecor` 行；要核对配方消耗看 recipes.lua 行号清单一节。
- 重要副作用：`SetSinks(true)`，丢进海里按水沉处理——生成 `splash_sink` 特效后实体被移除（[L40](../../../raw/current/scripts/prefabs/moonrocknugget.lua#L40)、[inventoryitem.lua L538-L549](../../../raw/current/scripts/components/inventoryitem.lua#L538-L549)、[ocean_util.lua L210-L255](../../../raw/current/scripts/ocean_util.lua#L210-L255)）；作祟只弹飞，不碎裂（见"常见陷阱与限制"）。
- 修改边界：本页不含月石祭坛（`moon_altar`，材料 `MATERIALS.MOON_ALTAR`）、带孔月岩（`moonrockcrater`，另一件 MOONROCK repairer，见关联导航）与月岛世界生成；月岩墙／月亮石本体机制只在"供料口径"里写到消费所需。

## 修复供料口径

- 修复判定走 `ACTIONS.REPAIR`：动作一次只取 1 件 `invobject`（重物搬运时取身上装备）交给目标 `repairable:Repair`（[actions.lua L984-L999](../../../raw/current/scripts/actions.lua#L984-L999)），成功后从堆叠里扣 1（[repairable.lua L148-L183](../../../raw/current/scripts/components/repairable.lua#L148-L183)）。
- 客户端能否出现动作取决于三段标签同时成立：目标 `repairable_moonrock`、目标 `healthrepairable` 或 `workrepairable`、手持物 `health_moonrock` 或 `work_moonrock`（[componentactions.lua L1679-L1698](../../../raw/current/scripts/componentactions.lua#L1679-L1698)）。
- 血量通道：`wall_moonrock` 的 `repairable.repairmaterial` 走 `data.name` 分支取到字符串 "moonrock"（[walls.lua L324-L327](../../../raw/current/scripts/prefabs/walls.lua#L324-L327)、[L395-L404](../../../raw/current/scripts/prefabs/walls.lua#L395-L404)），满血 600（[tuning.lua L2155](../../../raw/current/scripts/tuning.lua#L2155)）；每次 +40，**满血 600 时被拒**（`GetPercent() >= 1` 直接返回 false，[repairable.lua L106-L115](../../../raw/current/scripts/components/repairable.lua#L106-L115)）。
- work 通道：月亮石（`moonbase`）`MakeRepairable` 赋 `MATERIALS.MOONROCK`（[moonbase.lua L527-L534](../../../raw/current/scripts/prefabs/moonbase.lua#L527-L534)），`workable` 满值 `MOONBASE_COMPLETE_WORK` = 6、初始 `MOONBASE_DAMAGED_WORK` = 4，且 `SetWorkAction(nil)`——它没有可点的采掘动作，只能被攻击扣减或被修复（[moonbase.lua L678-L687](../../../raw/current/scripts/prefabs/moonbase.lua#L678-L687)、[tuning.lua L2147-L2148](../../../raw/current/scripts/tuning.lua#L2147-L2148)）；每次 +2，初始 4/6 时一件补满，从 0 起算则要 3 件（0→2→4→6）；修复后 `OnRepaired` 在 full 态移除 `repairable`（[moonbase.lua L499-L506](../../../raw/current/scripts/prefabs/moonbase.lua#L499-L506)），故满值没有 REPAIR 选项。
- 零工作量是条件掉落、不是采掘、也不是终身一次：`workleft <= 0` 时 `ToggleMoonCharge` 只在 `lootdropper == nil` 时挂组件并放 1–2 枚（[moonbase.lua L195-L206](../../../raw/current/scripts/prefabs/moonbase.lua#L195-L206)）；修回正工作量时 `else` 分支移除该组件（[L253-L254](../../../raw/current/scripts/prefabs/moonbase.lua#L253-L254)），因此"降零 → 修回 → 再降零"可以再次掉落。扣减方是攻击：月犬与月猪的攻击帧、月兽 spawner 都调 `WorkedBy(inst, 1)`（[SGhound.lua L765-L774](../../../raw/current/scripts/stategraphs/SGhound.lua#L765-L774)、[SGmoonpig.lua L264-L276](../../../raw/current/scripts/stategraphs/SGmoonpig.lua#L264-L276)、[moonbeastspawner.lua L128-L133](../../../raw/current/scripts/components/moonbeastspawner.lua#L128-L133)）。
- 两个数值不通用：40 只作用于有 `health` 的目标，2 只作用于有 `workable.workleft` 的目标；同一次 REPAIR 只命中 `address_repair_amount` 的首个匹配分支（health → workable → perishable → finiteuses，[repairable.lua L106-L142](../../../raw/current/scripts/components/repairable.lua#L106-L142)）。
- 检索范围：全 scripts 检索 `repairable.repairmaterial =`（25 处）与 `MATERIALS.MOONROCK`（6 处：`moonbase` 的 repairable、`moonrockcrater` 与 `moonrocknugget` 的 repairer、`walls.lua#L395` 与 `brokenwalls.lua#L102` 的墙体数据条目、`boat_bumpers.lua#L295` 的 workable 分支）。其中 `walls.lua#L395` 不是 `repairmaterial` 赋值，而是把墙体数据的 `name` 写成 "moonrock"、再由 `data.name` 等值落到 repairer／repairable（即上一段的血量通道），仍是可修目标；`brokenwalls` 与 `boat_bumpers` 不构成可修目标：前者只挂 inspectable／lootdropper／named／workable，没有 repairable（[brokenwalls.lua L72-L84](../../../raw/current/scripts/prefabs/brokenwalls.lua#L72-L84)），后者该分支在当前 4 条 bumper 数据（kelp／shell／yotd／crabking）里没有对应条目、且其 repairable 材料取 `data.material`（[boat_bumpers.lua L264-L267](../../../raw/current/scripts/prefabs/boat_bumpers.lua#L264-L267)、[L342-L386](../../../raw/current/scripts/prefabs/boat_bumpers.lua#L342-L386)）。因此"字面写了 `MATERIALS.MOONROCK` 的 repairable"仍只有月亮石一处；月岩墙是经 `data.name` 的等值分支接入。

## 常见陷阱与限制

- **误区：LaunchAndSmash 会碎**：helper 名为 LaunchAndSmash，但本快照把 smash 段整段注释（`#HAUNTFIX`），作祟只会弹飞物品；不要据此写"作祟会碎成月岩碎片"（[standardcomponents.lua L1084-L1101](../../../raw/current/scripts/standardcomponents.lua#L1084-L1101)）。
- **误区：40 与 2 是同一份修复量**：40 是血量修复、2 是 work 修复；月亮石在初始 4/6 时 1 件补满、被打到 0 后要 3 件（0→2→4→6），月岩墙按 1→600 的理论上限要 15 件（600 血、每件 40；新建墙初始只有 50% 血，常见补满约 8 件，[walls.lua L342](../../../raw/current/scripts/prefabs/walls.lua#L342)），两者不能互换推导（[tuning.lua L2128-L2129](../../../raw/current/scripts/tuning.lua#L2128-L2129)、[L2147-L2148](../../../raw/current/scripts/tuning.lua#L2147-L2148)）。
- **边界：满值不接受修复**：血量 \>= 100% 或 work 已满时 `address_repair_amount` 返回 false，动作不消耗物品；月亮石满态还直接移除了 `repairable`（[repairable.lua L106-L124](../../../raw/current/scripts/components/repairable.lua#L106-L124)、[moonbase.lua L499-L506](../../../raw/current/scripts/prefabs/moonbase.lua#L499-L506)）。
- **边界：落水即消失**：没有 `floater`，`SetSinks(true)` 让物品在非通行水面沉没并被移除，不能像盐晶／蜘蛛丝那样漂在水上捡回（[inventoryitem.lua L538-L549](../../../raw/current/scripts/components/inventoryitem.lua#L538-L549)、[ocean_util.lua L210-L255](../../../raw/current/scripts/ocean_util.lua#L210-L255)）。
- **边界：能装饰雪人 ≠ 玩家能吃**：`snowmandecor` 只负责动作收集、表项负责校验与渲染；`edible` 的 ELEMENTAL 类型玩家吃不掉，只有元素食性生物在组件层允许吃（回 10 生命），实际取食还要行为入口（尘蛾 dustmothfood、鼹鼠 molebait），三者互不推导（[snowmandecoratable.lua L33](../../../raw/current/scripts/components/snowmandecoratable.lua#L33)、[edible.lua L19-L24](../../../raw/current/scripts/components/edible.lua#L19-L24)、[eater.lua L18-L24](../../../raw/current/scripts/components/eater.lua#L18-L24)）。
