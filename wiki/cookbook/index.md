# cookbook 场景导航

新增对象／功能或需要多文件组装时，先沿用目标模组已有约定，再从本导航筛适用骨架；读其适用条件与所需 demo，按当前功能展开 reference 章节。已知骨架可直达，已有入口不重读起步页；局部机制修改／排查直接查本地实现与机制页。

没有适用骨架或扩展未覆盖时，查 [[reference/index|机制与接口参考]]；已知名称直接查相关页。仍有缺口再定向查源码，不必找到完全相同的组合案例，也不展开所有链接。

按起步、造物、扩展功能的顺序登记已交付场景；尚未交付的场景不建立空页或悬空入口。

| 入口 | 需求摘要 | 别名 / 状态 |
|---|---|---|
| [[cookbook/mod-starter|模组起步与加载验证]] | 建立 modinfo／modmain、全局读取代理并验证加载 | 新建模组、模组框架；active／source-reviewed |
| [[cookbook/new-item|新增可拾取物品]] | 在已有模组注册新物品，接入名称、原版外观／图标与检查／拾取，再按需扩展 | 新道具、物品 Prefab、可拾取物品骨架；active／source-reviewed |
| [[cookbook/equipment/index|装备场景]] | 按制作场景选装备骨架，再组合槽位与功能；当前已交付手部、身体护甲、头部 | 手持物、护符、护甲、帽子、服装、背包；仅已交付页可直达 |
